## 五、隐式原子能力（非命令，自动生效）

| 能力 | 说明 |
|---|---|
| **可用性校验** | 每条业务命令启动时自动校验 ehire 壳页 / login 页脚本基线（SHA-256 哈希守护 + gaea chunk 数量），结果缓存 6h，`51JOB_AVAILABILITY_REFRESH=1` 强制刷新；`doctor`/`shutdown`/`update`/`login` 免校验 |
| **三段式反检测** | ① 启动参数层（去自动化特征 + 最大化视口）② 页面注入层（webdriver 伪装 / asNative / console 时间差对抗）③ CDP 网络拦截（拦风控导航 Document、吞埋点上报 204） |
| **风控熔断** | 命中 403 / verify / security-check 立即停手，输出处理指引 |
| **百度 OCR** | `preview` 截图后自动识别为文本落盘 `~/.51job-cli/ocr/`；凭证走 `.env`（`API_KEY`/`SECRET_KEY` 或 `51JOB_BAIDU_*`），`51JOB_RESUME_OCR=0` 关闭，OCR 失败不影响预览结果 |
| **`.env` 配置** | `~/.51job-cli/.env`（用户级）→ `./.env`（项目级）→ 系统环境变量，三级覆盖（后读优先） |
| **会话锁 + 随机节流** | `~/.51job-cli/.cache/session.lock` 跨进程原子锁；命令间随机延迟（`51JOB_THROTTLE_*` 可调） |
| **站点分析技能** | `skills/51job-frontend-analysis/` capture 脚本归档线上 JS 到 `docs/research/51job-online-js/<date>/`（manifest + raw + analysis），用于基线更新与守卫复核 |
